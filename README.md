# Описание программы: Модель Ланчестера для плохоорганизованного боя

## 1. Описание математической модели

В основе программы лежит **линейный закон Ланчестера**, адаптированный для условий **плохоорганизованного боя**. 

Модель описывает сражение между двумя группировками (Красные и Синие), состоящими из однородных боевых единиц. Главная особенность модели заключается в том, что огонь распределяется равномерно по всей изначальной площади построения противника, включая уже пораженные цели. Это означает, что стрелки не переносят огонь на выживших, а продолжают «обрабатывать» сектор.

Симуляция останавливается автоматически при наступлении одного из событий:
1.  **Сдача в плен (подавление):** Оставшиеся силы одной из сторон превышают оставшиеся силы второй стороны в **3 раза**.
2.  **Физическое уничтожение:** Оставшиеся силы группировки составляют менее **5%** от её начального количества.

## 2. Возможности программы

*   **Интерактивное консольное меню:** Управление всеми процессами происходит через удобное текстовое меню, не требующее изменения исходного кода.
*   **Настройка параметров "на лету":** Вы можете изменять численность, вероятности попадания и темп стрельбы прямо во время работы программы.
*   **Численное решение ОДУ:** Для расчета используется решатель `scipy.integrate.solve_ivp` (метод Рунге-Кутты 4 порядка).
*   **Визуализация:** Программа автоматически строит график изменения численности сторон во времени с помощью библиотеки `matplotlib`, отмечая на нем критические уровни (5%) и точки окончания боя.
*   **Текстовый отчет:** После каждого расчета в консоль выводится подробный итог: время боя, остатки сторон в процентах и причина завершения сражения.
*   **Защита от ошибок:** Реализована остановка интегрирования при достижении нулевой численности, чтобы избежать математических ошибок и отрицательных значений.

## 3. Параметры модели

Все параметры задаются в функции `get_initial_parameters()` и могут быть изменены через меню программы.

| Параметр в коде | Описание | Единицы измерения |
| :--- | :--- | :--- |
| `N_k0` | Начальная численность Красных | ед. |
| `N_c0` | Начальная численность Синих | ед. |
| `P_k` | Вероятность поражения цели одним выстрелом (Красные) | от 0.0 до 1.0 |
| `P_c` | Вероятность поражения цели одним выстрелом (Синие) | от 0.0 до 1.0 |
| `lambda_rate_k` | Плотность потока выстрелов (Красные) | выстрелов / час |
| `lambda_rate_c` | Плотность потока выстрелов (Синие) | выстрелов / час |
| `lambda_eff_k` | *Вычисляемый параметр:* Эффективная скорострельность Красных | урон / час |
| `lambda_eff_c` | *Вычисляемый параметр:* Эффективная скорострельность Синих | урон / час |
| `t_max` | Максимальное время симуляции (предохранитель) | часы |
| `surrender_ratio` | Коэффициент превосходства для сдачи в плен (по умолчанию 3.0) | - |
| `destruction_ratio`| Коэффициент физического уничтожения (по умолчанию 0.05) | доля |

---

## 4. Как пользоваться программой

1.  Убедитесь, что у вас установлены необходимые библиотеки: `numpy`, `scipy`, `matplotlib`.
2.  Откройте файл со скриптом и нажмите **Run (F5)**.
3.  В консоли (Console) появится **Главное меню**.

```text
########################################
 ГЛАВНОЕ МЕНЮ (Модель Ланчестера) 
########################################
1. Текущие параметры
2. Задание параметров
3. Расчет (запуск и графики)
4. Выход
########################################
Выберите действие (1-4): 
```

### Пункты меню:

*   **1. Текущие параметры**
    *   Выводит на экран таблицу со всеми текущими значениями.
    *   Показывает вычисленную эффективную скорострельность (произведение вероятности на темп стрельбы).
    *   *После просмотра нажмите `Enter`, чтобы вернуться в меню.*

*   **2. Задание параметров**
    *   Программа по очереди спросит вас о каждом параметре (численность, вероятности, темп стрельбы и т.д.).
    *   Если вы хотите изменить значение, введите новое число и нажмите `Enter`.
    *   Если вы хотите оставить текущее значение без изменений, просто нажмите `Enter` (пустой ввод).
    *   *После ввода всех параметров нажмите `Enter`, чтобы вернуться в меню.*

*   **3. Расчет (запуск и графики)**
    *   Запускает симуляцию боя с текущими параметрами.
    *   В консоли отобразится результат (кто победил, время, потери).
    *   Откроется окно с графиком, где сплошными линиями показана динамика потерь, а пунктиром — порог 5% уничтожения.
    *   **Важно:** Закройте окно с графиком. В консоли появится запрос на нажатие `Enter`. Нажмите его, чтобы вернуться в главное меню (это нужно, чтобы вы успели прочитать текстовый результат боя).

*   **4. Выход**
    *   Завершает работу программы.
